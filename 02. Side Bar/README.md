# Sidebar Menu

A responsive sidebar menu built with HTML, CSS, and JavaScript.

## Project Overview

This project creates a hidden sidebar navigation panel that slides in from the left. It includes a hamburger open button, a close button, navigation links, and social media icons.

## Features

- Slide-in sidebar navigation
- Open and close buttons
- Responsive layout for small screens
- Social icon links in the sidebar

## Files

- `index.html` — page structure and sidebar markup
- `style.css` — styles for the sidebar and responsive behavior
- `script.js` — JavaScript to toggle the sidebar visibility

## How to Us
1. Open `index.html` in a web browser.
2. Click the hamburger button to open the sidebar.
3. Click the close button to hide the sidebar.

## Notes

- The sidebar links are currently placeholders (`#`).
- You can customize the colors, icons, and link labels as needed.

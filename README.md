# Responsive Menu

A simple responsive navigation bar built with HTML, CSS, and JavaScript.

## Project Overview

This project demonstrates a responsive navigation menu that transforms into a mobile-friendly hamburger menu on smaller screens. The layout uses a header with a logo, navigation links, and a login button.

## Features

- Responsive navigation bar for desktop and mobile
- Hamburger menu toggle on small screens
- Smooth menu animation using CSS transitions
- Clean layout with a modern dark header style

## Files

- `index.html` — page structure and navigation markup
- `style.css` — styling for desktop and responsive mobile menu
- `script.js` — JavaScript to toggle the menu visibility

## How to Use

1. Open `index.html` in a web browser.
2. Resize the browser window to see the mobile menu appear.
3. Click the hamburger icon to toggle the navigation links.

## Notes

- The menu links are currently placeholder links (`#`).
- You can replace the logo text with your own brand name or image.
- Add more navigation links or customize the colors to fit your design.
